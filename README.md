# Social Media Addiction Analysis

A data analysis and machine learning project that investigates the relationship between social media usage habits and academic performance.

## 📊 Project Contents

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Correlation analysis
- Data visualization
- Social media usage analysis
- Addiction score analysis
- Machine learning models

## 🧠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
